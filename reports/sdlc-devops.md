# SDLC and DevOps Mapping

## 1. Planning

DevOps activities:

- Infrastructure planning
- Release planning
- Capacity planning

## 2. Development

DevOps activities:

- Git and GitHub
- Code reviews
- Branching strategy
- CI automation

## 3. Testing

DevOps activities:

- Automated unit testing
- Integration testing
- Security testing

## 4. Build

DevOps activities:

- Jenkins
- Docker
- Automated builds

## 5. Security

DevSecOps activities:

- Trivy image scanning
- Dependency scanning
- Secret scanning
- SAST

## 6. Deployment

DevOps activities:

- Docker
- Docker Swarm
- Rolling deployment
- Blue-Green deployment

## 7. Operations

DevOps activities:

- Monitoring
- Logging
- Incident management
- Troubleshooting

## 8. Feedback

DevOps activities:

- Monitoring results
- User feedback
- Incident analysis
- Continuous improvement

## Conclusion

DevOps and DevSecOps practices can be integrated throughout the complete SDLC rather than being limited to deployment.
